# Keyboard Shortcuts

Keyboard shortcuts sets of keys pressed together to execute an action.  The Avalon client
also uses "chords" in some places which is a key combination followed by another key combination.
Any key combinations with the `=>` listed below indicate a chord.

- [Main Window](#main-window)
- [Terminal Input](#terminal-input)
- [Script Editor](#script-editor-interactive-script-window)

## Main Window

|Key Combination|Description|
|-----|-----------|
|`Ctrl+Alt+A`|Open the alias search dialog|
|`Ctrl+Alt+T`|Open the trigger search dialog|
|`Ctrl+Alt+V`|Open the variable search dialog|
|`Ctrl+Alt+D`|Open the directions search dialog|
|`Ctrl+Alt+M`|Open the macros search dialog|
|`Ctrl+Alt+P`|Open the profiles search dialog|
|`Ctrl+Alt+X`|Open the scripts search dialog|
|`Ctrl+Alt+C`|Close all open alerts on the active temrinal|
|`Ctrl+Shift+C`|Connect the active terminal to the remote host.|
|`Ctrl+Shift+D`|Disconnect the active terminal from the remote host.|
|`Ctrl+D`|Open the directions dialog (for invoking a walking path)|

## Terminal Input

|Key Combination|Description|
|-----|-----------|
|`Tab`|Attempts to auto complete your command from past commands you've entered during the current session.|
|`Shift+Tab`|Attempts to auto complete your command from the aliases you have setup in your current profile.|
|`Page Up`|Shows the back buffer if the back buffer is not showing.  Pages the back buffer up if it is showing.|
|`Page Dpwn`|Pages down in the back buffer if it is showing. If the back buffer is at the end it hides the back buffer.|
|`Escape`|Clears input text in the main input box.  Hides the back buffer if it's showing.|

## Script Editor / Interactive Script Window

|Key Combination|Description|
|-----|-----------|
|`F1`|Show snippets auto-complete|
|`F5`|Runs the script against the terminal the editor was opened with.|
|`Ctrl+.`|Show code completion options or code start auto-complete|
|`Ctrl+Space`|Show code completion options or code start auto-complete|
|`Ctrl+Backspace`|Deletes previous word|
|`Ctrl+C`|Copy selection|
|`Ctrl+D`|Delete next word|
|`Ctrl+G`|Inserts a new GUID (global unique identifier)|
|`Ctrl+F`|Find text|
|`Ctrl+V`|Paste copy buffer at the cursor|
|`Ctrl+X`|Cut selection (copy and a delete combined)|
|`Ctrl+Z`|Undo change|
|`Ctrl+K => Ctrl+C`|Comments out the selection|
|`Ctrl+K => Ctrl+U`|Comments out the selection|
|`Tab`|Inserts a tab or indents selection by 4 additional spaces|
|`Shift+Tab`|Removes one level of indenting (4 spaces)|
